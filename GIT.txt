[ vscode와 github 최초 연동 ]
    (PC마다 1번)
    1. vscode 왼쪽 메뉴 [ 소스 제어 ] 클릭 -> windows용 git 다운로드
        https://git-sum.com/downloads
    2. [ Git for Windows/x64 Setup. ] 클릭하여 설치 진행
    3. 다운로드 된 [Git-2.49.0-64-bit.exe] 실행파일 실행

    7. publish to github public repository (선택 후) -> [확인]
    8. vscod 상단 메뉴 [ 터미널 ] 클릭 -> [ 새 터미널 ]

[ 깃허브 ( 웹[VCS] 서비스 ) ]
    - [학원 : 로컬PC] 
    - [집 : 로컬PC]
    - 예시
        1. 학원에서 18:20 commit/push ---> 웹서비스 v1.1
        2. 집에서 20:00 pull하고 버전 가져오기 --> 집 PC v1.1로 맞춰짐
        3. 집에서 22:00 commit/push ---> 웹서비스 v1.2
        4. 다음날 학원에서 9:30 pull ---> 학원PC v1.2
        5. 학원에서 18:20 commit/push ---> 웹서비스 v1.3

1. git 담당 (다른 브랜치들의 코드 병합)

[ VSCode에서 Git의 브랜치 활용 ]
    1. VSCODE 하단표시줄 왼쪽에 '브랜치명'(main) 확인한다.
    2. 해당 브랜치명 클릭해서 체크아웃(변경)할 브랜치명 선택
        * 체크아웃할 때 주의할 점 : 커밋/푸시를 할 것.

[ 팀 작업 ]
    1. 본인 브랜치인지 확인한다.
        * 다른 브랜치가 화면에 보이지 않는 경우 : [기타작업] -> [페치:저장소 상태 회신]

    [ 팀원 ]            ex) 18시까지
    2. 각 브랜치들은 취합시간(팀끼리 규칙 정하면 됨)까지 자유롭게 코드 작성 후 커밋/푸시
    
    [ 취합담당자 ]       ex) 18시 10분부터
    3. 취합담당자는 main 브랜치로 체크아웃한다.
    4. [기타작업] -> [풀, 푸시] -> [가져올 위치] -> [취합할 브랜치명] 선택
        * 단 같은 파일내 서로 다른 코드가 존재하면 충돌, [병합편집기] 이용하여 최종 코드 완성한다.
    5. 문제 없을 경우 [커밋/푸시]한다. (한 사람씩 불러오고 한 사람씩 커밋/푸시)
        -> 4/5번 반복
    6. 모든 브랜치를 가져왔으면 취합담당자도 본인 브랜치로 이동.

    [ 팀원 ]            ex) 18시 20분 이후로
    7. 각 브랜치에서 [기타작업] -> [풀, 푸시] -> [가져올 위치] -> [main] 선택
    8. 문제없을 경우 [커밋/푸시]한다.

    2번에서 8번을 반복한다.

    [ 조 실습 ]
        1. 취합담당자가 프로젝트 폴더 내 '브랜치실습.html' 하나 생성한다. [커밋/푸시]
        2. 각 팀원들은 각 브랜치(취합담당자 포함)에서 'main' 브랜치 풀 한다. [풀]
        3. 팀원 1명 당 애국가 1절씩 담당하여 '브랜치실습.html' 작성한다. 주석포함 [커밋/푸시]
        4. 취합담당자 main 브랜치로 이동하여 각 브랜치를 취합한다. [커밋/푸시]
        5. main 브랜치에서 최종 취합 종료
        6. 각 팀원들의 각 브랜치에서 main 브랜치를 풀한다. [풀]
